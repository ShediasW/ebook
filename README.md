# ebook — PDF 이북 뷰어

PDF를 이북처럼 편하게 읽을 수 있는 웹앱입니다. 설치 없이 브라우저에서 동작합니다.

## 주요 기능

- **한 화면 한 페이지 (스크롤 없음)**: 텍스트가 화면보다 길면 전자책처럼 화면 크기 단위로 잘라서 넘김. 스크롤 대신 스와이프/방향키/좌우 탭으로만 이동
- **몰입 모드**: 읽는 동안 메뉴가 자동으로 숨고 글자만 표시. 화면을 탭하면 메뉴가 잠시 나타나고, 하단에 작은 페이지 위치 표시만 유지
- **리더 모드 (가독성)**: PDF에서 텍스트를 추출해 이북처럼 리플로우. 글꼴(명조/고딕), 글자 크기, 줄 간격, 본문 폭, 테마(라이트/세피아/다크) 조절 가능
- **원본 모드**: PDF 원본 레이아웃 그대로 보기 (텍스트 드래그 선택 가능)
- **문장 선택 번역**: 텍스트를 드래그하면 🌐 번역 버튼이 나타나고, 클릭 시 한국어 번역을 팝업으로 표시 (무료 Google 번역, API 키 불필요)
- **스캔 PDF 지원 (OCR)**: 텍스트 레이어가 없는 이미지 PDF는 자동으로 글자를 인식합니다. 인식 결과는 브라우저(IndexedDB)에 저장돼 재방문·재접속 시 재인식 없이 즉시 표시
- **고정밀 클라우드 OCR (선택)**: 설정(⚙)에서 **Naver CLOVA OCR**(한국어 정확도 97~99%) 또는 **Google Vision**을 선택하고 본인 API 키를 입력하면, 한글 스캔본도 띄어쓰기까지 깔끔하게 인식됩니다. 키가 없으면 기본(기기 내 Tesseract, 무료)으로 동작 — 아래 [고정밀 OCR 설정](#고정밀-클라우드-ocr-설정) 참고
- **배경 일괄 인식 (⚡)**: 툴바의 ⚡ 버튼을 누르면 문서 전체를 백그라운드로 미리 인식해 둡니다. **기기 성능에 맞춰 여러 워커로 병렬 처리**해 아이폰 멀티코어에서 2배가량 빠릅니다. 읽는 중에도 진행되며(보는 페이지에 우선권 양보), 좌하단에 진행률이 표시됩니다. 한 번 인식해 두면 어느 페이지로 넘어가도 즉시 열립니다. 중간에 멈춰도(다시 눌러 중지) 다음에 이어서 진행됩니다
  - 인식 중에는 **화면이 자동으로 꺼지지 않게 유지**(Screen Wake Lock)해서, 폰을 내려놓아도 끝까지 돕니다. 앱을 벗어나 잠갔다가 돌아오면 멈췄던 지점부터 자동으로 이어집니다
  - ⚠️ iOS 제약상 **다른 앱으로 완전히 전환하거나 수동으로 화면을 끄면** 인식은 일시 정지됩니다(웹앱은 백그라운드에서 계속 계산할 수 없음). 앱을 켜 두면 화면 잠금 없이 계속 진행됩니다
- **대용량 PDF 대응**: 수백 MB 스캔본도 파일을 통째로 메모리에 올리지 않고 **필요한 부분만 읽어 스트리밍**으로 엽니다. 페이지를 넘겨도 메모리를 회수해 아이폰에서도 크래시 없이 열립니다
- **이어읽기**: 파일별 마지막 페이지와 읽기 설정을 자동 저장

## 아이폰에서 사용하기

1. 저장소에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다 → **https://shediasw.github.io/ebook/**
2. 아이폰 Safari에서 위 주소를 열고 "PDF 파일 열기"를 누르면 파일 앱/iCloud에서 PDF를 선택할 수 있습니다.
3. 자주 쓴다면 공유 버튼 → **"홈 화면에 추가"** 를 하면 전체 화면 앱처럼 실행됩니다.

모바일 전용 동작: 좌우 **스와이프**로 페이지 넘김, 화면 좌우 가장자리 탭으로도 이동, 텍스트를 길게 눌러 선택하면 🌐 번역 버튼이 나타납니다. 읽는 중에는 메뉴가 자동으로 숨겨지며, **화면 가운데를 탭**하면 다시 나타납니다.

## 실행 방법 (PC, 로컬)

정적 파일 서버만 있으면 됩니다. 저장소 루트에서:

```bash
# Python이 있는 경우
python3 -m http.server 8000

# 또는 Node.js가 있는 경우
npx serve .
```

브라우저에서 `http://localhost:8000` 을 열고 PDF 파일을 드래그하거나 "PDF 열기" 버튼으로 선택하세요.

> PDF는 서버로 업로드되지 않고 전부 브라우저 안에서 처리됩니다.
> 라이브러리(PDF.js, Tesseract.js)와 번역 요청은 인터넷 연결이 필요합니다.

## 사용 팁

- **텍스트가 있는 PDF(OCR 완료본)**: 바로 리더 모드로 읽을 수 있습니다.
- **스캔(이미지) PDF**: 페이지를 열면 자동으로 글자 인식이 실행됩니다. 첫 실행 시 언어 데이터 다운로드로 시간이 조금 걸릴 수 있고, 인식된 페이지는 캐시되어 다시 열면 즉시 표시됩니다. 설정(⚙)에서 OCR 인식 언어를 바꿀 수 있습니다.
- **대용량 스캔본 팁**: 문서를 연 뒤 ⚡ 버튼을 눌러 두면 나머지 페이지를 백그라운드로 미리 인식합니다. 그동안 계속 읽을 수 있고, 인식이 끝나면 어느 페이지든 기다림 없이 열립니다. (배터리·데이터 절약을 위해 Wi-Fi·충전 중 사용을 권장)
- **번역**: 리더 모드/원본 모드 어디서든 문장을 드래그하면 번역할 수 있습니다. 무료 번역은 짧은 시간에 많이 요청하면 일시적으로 제한될 수 있습니다.

## 고정밀 클라우드 OCR 설정

한글 스캔본의 인식 품질이 중요하면 클라우드 엔진을 권장합니다. 키는 **이 기기(브라우저)에만 저장**되며, 인식할 페이지 이미지가 해당 클라우드로 전송됩니다. 한 번 인식한 페이지는 기기에 영구 저장되어 다시 과금되지 않습니다.

| 엔진 | 한국어 정확도 | 무료 한도 | 초과 요금(대략) | 500쪽 책 1권 |
|---|---|---|---|---|
| **Naver CLOVA** (권장) | 97~99% | 플랜별 상이 | 쪽당 수 원 | 약 1천 원 안팎 |
| **Google Vision** | 90~93% | 월 1,000쪽 | $1.5/1,000쪽 | 첫 권 무료 수준 |

### Naver CLOVA OCR 키 발급

1. [NAVER Cloud Platform](https://www.ncloud.com) 가입 → 콘솔 → **AI Services → CLOVA OCR**
2. **도메인 생성**(General, Basic 플랜) → 생성된 도메인의 **APIGW 연동** 설정
3. 도메인 정보에서 **Invoke URL**과 **Secret Key** 복사
4. 앱 설정(⚙) → OCR 엔진 → *CLOVA OCR* 선택 → URL·Secret 입력 → **키 확인**
5. 만약 "호출이 차단되었습니다(CORS)" 오류가 나면 브라우저 직접 호출이 막힌 것입니다 →
   [`proxy/clova-worker.js`](proxy/clova-worker.js)의 안내대로 Cloudflare Worker(무료)를 5분 만에 배포하고,
   Worker 주소를 Invoke URL 자리에 넣으세요(Secret은 Worker에 보관되므로 앱에서는 비움)

### Google Vision 키 발급

1. [Google Cloud Console](https://console.cloud.google.com) → 프로젝트 생성 → **Cloud Vision API 사용 설정**(결제 계정 필요)
2. API 및 서비스 → 사용자 인증 정보 → **API 키** 생성
3. 키 보안을 위해 **애플리케이션 제한사항 → HTTP 리퍼러**에 `https://shediasw.github.io/*` 추가 권장
4. 앱 설정(⚙) → OCR 엔진 → *Google Vision* 선택 → 키 입력 → **키 확인**

### 요금 안전장치

- 배경 일괄 인식(⚡) 실행 전에 **예상 쪽수·요금 확인 창**이 뜹니다
- 이미 인식된 페이지는 건너뛰므로 중단·재개해도 중복 과금되지 않습니다
- 한도 초과(429)·키 오류 시 배경 인식이 즉시 중지되고, 해당 페이지는 기기 내 인식으로 대체됩니다

## 기술 구성

- 빌드 도구 없는 정적 웹앱 (HTML + CSS + ES 모듈 JavaScript)
- [PDF.js](https://mozilla.github.io/pdf.js/) — PDF 렌더링·텍스트 추출 (CDN). 로컬 파일은 `File.slice` 기반 range 스트리밍으로 로드해 대용량도 저메모리로 처리
- [Tesseract.js](https://tesseract.projectnaptha.com/) — 브라우저 내 OCR (CDN)
- IndexedDB — OCR 결과 영구 캐시 (재인식 방지)
- Google 번역 무료 엔드포인트 — 문장 번역
