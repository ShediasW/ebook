# ebook — PDF 이북 뷰어

PDF를 이북처럼 편하게 읽을 수 있는 웹앱입니다. 설치 없이 브라우저에서 동작합니다.

## 주요 기능

- **한 화면 한 페이지 (스크롤 없음)**: 텍스트가 화면보다 길면 전자책처럼 화면 크기 단위로 잘라서 넘김. 스크롤 대신 스와이프/방향키/좌우 탭으로만 이동
- **몰입 모드**: 읽는 동안 메뉴가 자동으로 숨고 글자만 표시. 화면을 탭하면 메뉴가 잠시 나타나고, 하단에 작은 페이지 위치 표시만 유지
- **리더 모드 (가독성)**: PDF에서 텍스트를 추출해 이북처럼 리플로우. 글꼴(명조/고딕), 글자 크기, 줄 간격, 본문 폭, 테마(라이트/세피아/다크) 조절 가능
- **원본 모드**: PDF 원본 레이아웃 그대로 보기 (텍스트 드래그 선택 가능)
- **문장 선택 번역**: 텍스트를 드래그하면 🌐 번역 버튼이 나타나고, 클릭 시 한국어 번역을 팝업으로 표시 (무료 Google 번역, API 키 불필요)
- **스캔 PDF 지원 (OCR)**: 텍스트 레이어가 없는 이미지 PDF는 Tesseract.js로 브라우저에서 자동 OCR (영어/한국어)
- **이어읽기**: 파일별 마지막 페이지와 읽기 설정을 자동 저장

## 아이폰에서 사용하기

1. 저장소에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다 → **https://shediasw.github.io/ebook/**
2. 아이폰 Safari에서 위 주소를 열고 "PDF 파일 열기"를 누르면 파일 앱/iCloud에서 PDF를 선택할 수 있습니다.
3. 자주 쓴다면 공유 버튼 → **"홈 화면에 추가"** 를 하면 전체 화면 앱처럼 실행됩니다.

모바일 전용 동작: 좌우 **스와이프**로 페이지 넘김, 화면 좌우 가장자리 탭으로도 이동, 텍스트를 길게 눌러 선택하면 🌐 번역 버튼이 나타납니다. 읽는 중에는 메뉴가 자동으로 숨겨지며, **화면 가운데를 탭**하면 다시 나타납니다.

## 실행 방법 (PC, 로컬)

정적 파일 서버만 있으면 됩니다. 저장소 루트에서:

```bash
# Python이 있는 경우
python3 -m http.server 8000

# 또는 Node.js가 있는 경우
npx serve .
```

브라우저에서 `http://localhost:8000` 을 열고 PDF 파일을 드래그하거나 "PDF 열기" 버튼으로 선택하세요.

> PDF는 서버로 업로드되지 않고 전부 브라우저 안에서 처리됩니다.
> 라이브러리(PDF.js, Tesseract.js)와 번역 요청은 인터넷 연결이 필요합니다.

## 사용 팁

- **텍스트가 있는 PDF(OCR 완료본)**: 바로 리더 모드로 읽을 수 있습니다.
- **스캔(이미지) PDF**: 페이지를 열면 자동으로 글자 인식이 실행됩니다. 첫 실행 시 언어 데이터 다운로드로 시간이 조금 걸릴 수 있고, 인식된 페이지는 캐시되어 다시 열면 즉시 표시됩니다. 설정(⚙)에서 OCR 인식 언어를 바꿀 수 있습니다.
- **번역**: 리더 모드/원본 모드 어디서든 문장을 드래그하면 번역할 수 있습니다. 무료 번역은 짧은 시간에 많이 요청하면 일시적으로 제한될 수 있습니다.

## 기술 구성

- 빌드 도구 없는 정적 웹앱 (HTML + CSS + ES 모듈 JavaScript)
- [PDF.js](https://mozilla.github.io/pdf.js/) — PDF 렌더링·텍스트 추출 (CDN)
- [Tesseract.js](https://tesseract.projectnaptha.com/) — 브라우저 내 OCR (CDN)
- Google 번역 무료 엔드포인트 — 문장 번역
